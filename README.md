# Bipsa Shrestha - Portfolio

A modern, responsive frontend developer portfolio built with HTML5, CSS3, and JavaScript.

## 🚀 Features
- **Responsive Design**: Looks great on mobile, tablet, and desktop devices.
- **Modern UI**: Clean typography, glassmorphism cards, and smooth CSS transitions.
- **Projects Showcase**: Highlights key projects with tags, descriptions, and action links.
- **Interactive**: Mobile navigation drawer and interactive contact form.

## 🛠️ Tech Stack
- HTML5 (Semantic Markup)
- CSS3 (Custom properties, Flexbox, Grid, Animations)
- JavaScript (ES6+)
